# CW 交叉臂（Cross-Arm）评估结果 — 3×3 矩阵

- **设计**：固定红方 checkpoint，分别在 3 个蓝方 checkpoint 环境中评估（行内对比 = 蓝方供给侧效应）；固定蓝方换红方（列内对比 = 红方策略效应）。
- **checkpoint**：`V94_Retrain{A,B1,B2}_25host_s1/{red,blue}_agent.pt`，混合目录 `V94_Cross_red{X}_blue{Y}`。
- **口径**：拓扑 25host（`topology_25h.yaml` / `25-host-network.yaml`）、`CYBERWHEEL_SYNC_RED_TARGETS=1`（sync1）、每组合 5 集 × 100 步（种子 101–105，每集独立进程独立种子，与 EXP-1 口径一致）、deterministic。
- **指标**：D-Score = wxpgzs `metrics_table.csv` 末行聚合值；decoy-strike 率 = 红方动作目标 ∈ 诱饵清单（`.decoys.json` 并集口径，any-target）的步数占比；控制率 = `node_control_rate`（终值 / 全集均值）；蓝方部署数 = 每集诱饵清单条数均值。
- **产物**：语料 `data/cw_supplement/cross_arm/corpus/`（45 × csv+.decoys.json+.run.json）；wxpgzs 指标 `cross_arm/metrics/`；每集明细 `cross_arm/per_episode.csv`。
